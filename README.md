# 🏋️ ApexAthlete

### Fitness, Workout & Wellness Website

ApexAthlete is a responsive fitness and wellness website that helps users explore workout programs, diet plans, fitness classes, BMI analysis, and user authentication.

## ✨ Features

- 🏠 Modern and responsive homepage
- 💪 Fitness and wellness services
- 🏋️ Interactive workout classes
- ▶️ YouTube workout video integration
- 🥗 Diet plans for different fitness goals
- 🧮 BMI calculator
- 🔐 User registration and login using Firebase Authentication
- 🔑 Forgot password functionality
- 📱 Responsive design for desktop, tablet, and mobile
- 🎨 Interactive UI with animations and hover effects

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Firebase Authentication
- YouTube Embed
- Remix Icon
- ScrollReveal
- Google Fonts

1. Clone or download the repository.
2. Open the project in **Visual Studio Code**.
3. Open `index.html` using **Live Server**.
4. Explore the website.

## 🔥 Firebase Authentication

Firebase Authentication is used for:

- User registration
- User login
- Password reset

The project uses **Email/Password authentication**.

To use your own Firebase project, update the Firebase configuration in the project files with your Firebase Web App configuration.

## 🧮 BMI Calculator

Users can enter their height and weight to calculate their BMI.

The calculation is performed using JavaScript:

```text
BMI = Weight (kg) / Height² (m²)
```

The result is classified as:

- Underweight
- Normal Weight
- Overweight
- Obese

## ▶️ Workout Videos

Users can select a workout class and watch the corresponding YouTube video directly on the website through a video modal.
